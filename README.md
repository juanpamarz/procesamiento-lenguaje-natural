# Procesamiento de Lenguaje Natural: Analisis de Frecuencia de Palabras en Canciones

Este repositorio contiene una practica academica de procesamiento de lenguaje natural (PLN) desarrollada en Python utilizando la libreria NLTK. El proyecto realiza el analisis de texto de la letra de una cancion, aplicando limpieza, tokenizacion, filtrado de conectores y visualizacion de frecuencias.

## Descripcion del Proyecto

El objetivo de esta practica es procesar un archivo de texto plano que contiene la letra de una cancion para extraer informacion estadistica y semantica relevante, eliminando elementos de ruido como signos de puntuacion y palabras vacias (stopwords).
